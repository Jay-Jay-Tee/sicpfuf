# Past-paper study routes

These routes use the three PDFs in the supplied `Final_export.zip`. They connect question
groups to the skills taught here. Use your local copies for the actual questions; this page
does not reproduce the papers or provide an official answer key.

For each group: read the linked explanation, attempt the paper without notes, then use the
drills or interpreter to investigate the mistake. Record *why* an answer was wrong: model,
representation, base case, evaluation order, aliasing, or resource count.

## Using the midterms and reading assessments

The other supplied archives include older papers and answer PDFs. Read the question before
opening its answer. For current-year RA variants, the supplied ZIPs contain answer variants
without separate question PDFs; do not assume a missing question file has been reviewed.

Older papers are practice material, not a specification of the current final's scope. In
particular, use the current [typed chapter](../book/19-types-objects.md) and
[typed drills](../practice/15-types.md) even when an older paper does not test those rules.

For a complete route through the available lectures and sheets, return to the
[course map](../book/course-map.md). For timed practice with checked original solutions,
use the [mock papers](index.md).
