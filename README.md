# sicpfuf

**Python §1–§4 with x-ray vision**: an unofficial study companion for SICP in Python (SICPy).

Work in progress. See `docs/` for the finals kit, drills and book as they land.

    python3 -m sicpfuf program.py -v 2        # run a program as Python §2
    python3 tests/run_tests.py                # run the tests
